# Release note type mapping

## Section to RN Type

| Section | Default RN Type |
|---|---|
| 1. New features and enhancements | Enhancement (or Feature if clearly new) |
| 2. Technology Preview features | Technology Preview |
| 3. Developer Preview features | Developer Preview |
| 4. Deprecated features | Deprecated Functionality |
| 5. Removed features | Removed Functionality |
| 6. Known issues | Known Issue |
| 7. Fixed issues | Bug Fix |
| Unclassified | Must classify first |

## RN Type to style guide file

| RN Type | Type file |
|---|---|
| Enhancement, Feature | `release-notes-type-features.md` |
| Rebase | `release-notes-type-rebases.md` |
| Technology Preview | `release-notes-type-tech-preview.md` |
| Deprecated Functionality | `release-notes-type-deprecated.md` |
| Removed Functionality | `release-notes-type-removed.md` |
| Known Issue | `release-notes-type-known-issues.md` |
| Bug Fix | `release-notes-type-fixed-issues.md` |
